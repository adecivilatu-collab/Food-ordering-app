# Phase 2 — Wireframes (low-fi, bright v0.2)
All screens use tokens.css. Sticky cart bar, bottom-sheet customize, skeleton loaders.

1. Location gate: big Search + Use current location + saved chips. CTA Continue.
2. Home: search top, category row (Nigerian/African/Fast Food/Pizza/Burgers/Chicken/Rice/Shawarma/Chinese/Bakery/Desserts/Drinks/Healthy), Nearby cards, Popular, Deals banner (accent yellow), Recent (registered).
3. Restaurant page: banner 16:9, name/rating/ETA/fee/open badge, tabs Menu/Reviews/Info, popular dishes first.
4. Food sheet: 1:1 photo, price 18px, option groups (rice/protein/portion/add-ons), instructions, Qty + Add ₦X.
5. Cart: rows + instructions, fee rows (subtotal/fee/service/discount), Total 20px, Checkout CTA.
6. Checkout: address picker, name/phone(+234), instructions, payment radio (5 methods, COD gated), policies link, Pay ₦X.
7. Tracking: confirmation (orderNo/ETA) + timeline (7 states) + Leaflet map + rider ETA + support button per order.
8. Restaurant dashboard: New/In-progress/Ready columns, Accept/Reject, menu table with availability toggle.
9. Rider: request cards (fee/distance/pickup), delivery detail (codes, instructions), status buttons.
10. Admin: queues (approvals), order search, payment refs, promo editor, review moderation, refund tool.
