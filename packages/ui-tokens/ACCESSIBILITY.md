# Phase 1 — Accessibility Checklist
- [ ] Contrast: black #0B0B0B on #FF5A00/#FFD600/#00C853/#00B0FF passes; white only on #C43D00/#007A33/#FF1744.
- [ ] Touch targets ≥44px for all buttons/inputs/steppers.
- [ ] Prices ≥16px, descriptions ≥14px.
- [ ] Focus visible (3px outline) on all interactives.
- [ ] Screen reader: alt on restaurant/food images, labels on phone/search/OTP, status announced on timeline.
- [ ] Sunlight: test bright palette outdoors; no muted-gray-on-white text.
- [ ] Low data: compressed images, blur-up placeholders, no autoplay.
- [ ] Keyboard: full checkout flow without mouse.
